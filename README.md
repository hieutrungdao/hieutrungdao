### 🔭 Research direction

Trained LLMs are static — knowledge and behavior are frozen at training time, which makes the
model itself the bottleneck for deployed agents. I'm working on moving optimization from
**weight space to text space**: self-evolving agents and harnesses that refine their own skills,
prompts, and memory on the fly, without retraining.
